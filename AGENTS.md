# AI-Framework

## Agent skills

### Issue tracker

Issues live in GitHub Issues (`AndrewGodlewsky/AI-Framework`) via the `gh` CLI.
External PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

Canonical defaults — each role's label string equals its name.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `CONTEXT.md` and `docs/adr/` at the repo root.
See `docs/agents/domain.md`.

## Wayfinder tickets

Work on this repo is charted as a wayfinder map:
[#1 Map: The AI Usage Spectrum](https://github.com/AndrewGodlewsky/AI-Framework/issues/1).

Every ticket issue carries a `## Skills` section in its body naming the skills to drive it with.
**Read and follow that section before starting work on the ticket** — it is the authoritative
instruction for how that ticket gets resolved, not a suggestion.
